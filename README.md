# 💻 TECH CHALLENGE — Código Cruzado

> **Desafie seus conhecimentos em Arquitetura de Computadores!**

O **Código Cruzado** é um jogo de palavras cruzadas desenvolvido para testar e reforçar conhecimentos sobre Arquitetura de Computadores de uma forma interativa e divertida.

Com uma interface inspirada em um laboratório de tecnologia, o jogador precisa interpretar as pistas e descobrir os conceitos relacionados ao funcionamento dos computadores e seus componentes.

## 🎮 Como jogar

1. Acesse o jogo pelo navegador.
2. Observe as pistas divididas entre horizontais e verticais.
3. Selecione uma palavra no tabuleiro.
4. Leia a pista correspondente.
5. Digite sua resposta nas casas disponíveis.
6. Complete as 16 palavras e teste seus conhecimentos!

**Objetivo:** preencher toda a cruzadinha corretamente utilizando seus conhecimentos sobre Arquitetura de Computadores.

## 🧠 Sobre o desafio

O jogo possui **16 palavras** relacionadas a conceitos fundamentais da Arquitetura de Computadores, incluindo:

- Processador e seus componentes;
- Memórias e armazenamento;
- Barramentos de comunicação;
- Unidade de Controle e ULA;
- Tecnologias de memória;
- Transferência de dados.

Cada palavra possui uma pista que ajuda o jogador a encontrar a resposta correta.

## 🎨 Interface

O projeto utiliza uma identidade visual tecnológica, com tons escuros, detalhes em verde e uma interface organizada para proporcionar uma experiência intuitiva ao jogador.

## 📱 Responsividade

A interface foi desenvolvida para se adaptar a diferentes tamanhos de tela, permitindo jogar tanto em computadores quanto em dispositivos móveis.

## 👨‍💻 Desenvolvimento

Projeto desenvolvido como atividade acadêmica da disciplina de **Arquitetura de Computadores**, com o objetivo de transformar conteúdos estudados em uma experiência interativa.
